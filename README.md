## Developer Mindset

Software development, for me, is a cycle: learn something, build with it, get it wrong, figure out why, and improve. Most of my projects started because I wanted to see if something I read actually worked — and several of them taught me more from being wrong than from being right. I like that process, and I'm still early in it.
